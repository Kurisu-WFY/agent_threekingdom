# 真实核查与有限纠错

网页文化问答及本地文化问答采用：生成初稿 → 核对当前知识库证据 → 按缺口补检索 → 模型修订 → 再检查。最多两轮，不播放模拟思考，也不输出模型内部推理。无问题不发起修订；规则检查不等于历史事实全部验证。

## 已接通

- 出处遗漏、已返回资料的观点覆盖、部分原文引句与PDF页码检查；故里碑、万卷楼等高风险定论规则。
- 无法解决的阻断问题改为按出处摘录；补查异常也撤去已发现的不当初稿。其他无法核查情况明确标为核查未完成。
- 女娲网页修订沿用原会话调用原智能体，不用本地文本假扮远端回答。额外调用可能增加等待时间。
- 页面等待区显示真实补查／修订状态，最终附折叠的“核查与修订说明”。没有召回率、分块数量或思维链。
- MCP新增史料核查、行程约束核查。行程工具核对输入时长、预算与未知费用，不验证实际路况、空房或实时价格；未知值必须为null，不能随意补成零。

## 女娲本地智能体启用

1. NuwaClaw配置 → MCP：停用再启用本项目服务，使新工具定义生效。
2. 将prompts/nuwax_agent_system_prompt.md的系统词同步到平台并发布，开启新对话。网页用户词由服务端自动加载。
3. 要求智能体先生成初稿，调用史料核查；存在问题按工具返回的补查词检索、修订、再核查，最多两轮。行程使用真实API耗时与用户预算填入行程核查。

网页文化回答后端自动执行闭环；平台内直接聊天是否调用核查工具取决于平台工具挂载与提示词，不能仅凭本地文件修改认定远端已启用。行程工具已可调用，但不是所有旧路线生成入口都自动执行重规划。

## 验证与边界

tests/test_reflection.py的7项断言验证补查、修订、两轮停止、无伪修订、失败安全、引文页码风险、约束核对及女娲同会话单结果。远端修订响应为测试替身，不代表真实女娲效果实测。

目前是有限的可验证规则与证据闭环，不是通用史学审稿系统；未检出的语义错误仍可能存在。文献缺项补列只表示出处覆盖，不代表每篇观点已充分展开。相关PDF与BGE索引未重新写入。
