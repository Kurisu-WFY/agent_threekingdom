# Agent 产品框架

## 核心一句话

川东北三国文化主题全流程旅游智能体：用一个 Agent 完成攻略整理、路线规划、动态陪游和分层文化讲解。

## 四个 Agent 模块

### 1. Intent Router

判断用户意图：

- 历史文化问答
- 正史/演义辨析
- 路线规划
- 行中动态调整
- 预算/票务查询
- 景点讲解

### 2. Culture Guide Agent

负责基于 RAG 生成文化讲解。

叙事模式：

- parent_child：亲子故事版
- public：大众体验版
- academic：学术探索版

回答原则：

- 区分事实、推测、主观推荐
- 不把《三国演义》情节默认当正史
- 对没有证据的内容提示“不确定”

### 3. Route Planner Agent

根据时间、交通、人群、兴趣、预算生成路线。

输出：

- 景点顺序
- 时间安排
- 交通方式
- 推荐理由
- 对应叙事阶段
- 预算估算
- 备选方案

### 4. Dynamic Scheduler Agent

根据现场变量调整路线。

变量：

- 当前定位
- 剩余时间
- 景点开放状态
- 演出时间
- 排队/拥堵
- 天气
- 用户疲劳程度

约束：

- 路线可以变，叙事主线不能乱。
- 调整必须解释原因。
- 没有实时数据时，只能输出“模拟调度建议”。

## 叙事主线

```text
寻源：认识记录三国的人
读史：走进陈寿记录的蜀汉
探迹：从文字走向现实空间
传承：今天如何理解三国文化
```

## MVP 范围

P0：

- 三国文化问答
- 陈寿相关问答
- 一日路线生成
- 三种讲解模式
- 正史/演义辨析

P1：

- 攻略截图/链接解析
- 预算聚合
- 动态路线模拟调度

P2：

- 实时地图
- 实时票务
- AR
- 数字人
- 多语言
