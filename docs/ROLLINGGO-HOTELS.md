# 女娲住宿查询接入

本项目通过已安装的 RollingGo 技能代理读取本机授权，供 `san-guo-travel-agent` 提供住宿查询。单独安装技能目录不会使女娲自动获得工具，因此增加三个查询工具：授权状态、酒店搜索、房型及价格详情。工具同样可从标准输入输出和HTTP入口发现。

## 使用

1. 在本机完成 RollingGo 官方授权。授权由官方程序保存，项目不复制凭据进仓库。
2. 女娲客户端「配置 → MCP」中禁用再启用 `san-guo-travel-agent`，新建对话以发现酒店工具。
3. 提问例如「查询南充万卷楼附近2026年10月4日入住，住1晚，2位成人的3家酒店，只查询参考价」。日期应随实际需要调整。
4. 指定搜索返回的酒店后，可以查询房型、币种、总价和取消政策。展示价为参考价，不是已锁定价格。

网页用户模板已加入查询规则。平台系统提示词可同步 `prompts/nuwax_agent_system_prompt.md`，本项目不会自动发布远端提示词。

## 本机依赖

- 官方技能目录由 `ROLLINGGO_SKILL_DIR` 指定，默认用户目录 `.codex/skills/rollinggo-hotel-booking`。
- Node由 `ROLLINGGO_NODE_PATH` 指定；酒店程序已通过官方npm包安装。
- 查询经过技能代理并先读取实时命令帮助；地点参数拒绝Windows命令解释器特殊字符，工具只接受固定查询，不接受任意命令。
- 该接入使用本机OAuth，和DIDA远程MCP的API Key认证是两条不同路径。无需把高德密钥或女娲密钥填给酒店服务。
- 当前提供酒店搜索和房型查询，不暴露锁价、下单、支付、订单查询或取消工具。

## 验证

已通过5项参数与授权回归测试，真实标准输入输出工具发现验证通过。报价实际测试需官方授权完成；未授权时返回明确状态，不生成假报价。
