# 新版前后端适配（2026-10-05）

- 保留新版布局，只增加同源章节加载与住宿卡片。
- `/api/travel/stories/chenshou-book-history` 提供三章现代研究阅读内容。
- 内容清单在 `data/content/chenshou-book-history.json`；三章各自映射编纂背景、人物关系，第二、三章各含两条归属作者的争议观点，引用独立解析到 PDF 页码；缺引用时对应栏目标待核验。
- 万卷楼、汉桓侯祠、剑门关、昭化古城、米仓道均有独立文化介绍。旅游论文标 C 级线索，不能独立证明史实；米仓道是历史地理说明，不冒充现代可通行路线，五处坐标仍为空。
- 文献链接通过索引与明确补充清单白名单提供，不接受任意文件路径，不向浏览器返回本机路径。补充的宋健、李科治两篇通过原文件 SHA256 与实际 PDF 页数核验，只用于固定正文展示，不代表已向量化。
- 陈寿摘要及隐藏对话上下文使用当前章论文正文与出处；阅读地点资料保持当前章节，不再因共用万卷楼而跳回第一章。
- 这些章节均以万卷楼为阅读锚点，不构造陈寿生平地理路线；当前仅对所列论文作内容映射，不代表全库自动映射。
- 文化阅读区新增“现代研究解读”类别，不能把 B 级论文转述当作已经核验的正史原文。
- 活动计划兼容空住宿档位、豪华型和行政区代码；高档型沿用原有品质型别名。
- 前端、MCP 共用高德天气函数，返回供应商实际日夜预报，不查询空气质量、不保证超过供应商预报范围。
- 网页住宿走同源酒店搜索，复用 RollingGo 授权。当前页面查询一晚、每房两位成人；未实现星级筛选、多晚和房型选择，不下单、不支付。
