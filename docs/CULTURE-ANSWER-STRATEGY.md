# 关键文化问题的有据回答策略

## 当前规则

文化问答默认不再只给简略结论：先解释史籍的实际记载，再解释历史背景，逐篇归纳本次相关研究，存在争议时对照不同作者观点，最后关联景点与证据边界。用户明确要求简短时压缩正文；亲子模式简化表达，不把文学、传闻说成史实。

古代正文、注释引书、传闻、现代研究、演义与地方传说分别归属。人物生平不能单独证明现代墓址、祠庙或万卷楼建筑的真实性。原典未返回时不能声称已核对原文。

## 检索如何改动

- 原文化问答固定最多五个最终片段，降级回答只摘前三段；保留旧HybridRetriever路径作兼容，新的文化问答和MCP改用 `src/rag/document_evidence.py`。
- 对当前已入库的全部片段做原问题向量检索及词项匹配，再按人物、主题与相关性筛选。不是将知识库全部内容无差别列出，也不把扩展查询附加词当作用户的检索条件。
- 按文献标识去重，每份取最多三条代表证据，保留题名、来源、篇章和真实PDF页码。文献数不再受五片段上限限制；同一文献多个片段不算多个来源。相关性阈值可在Settings中配置，不能承诺所有可能相关资料均能被算法召回。
- MCP返回 `references`、`has_more`、`next_offset`；默认每页八份来源，最多十二份。智能体须保持原问题继续分页，直至没有下一页；多主题分开检索后去重。
- 本地模型输出上限从1500增加到4096令牌，只作用本地AnswerChain，不更改女娲平台模型的输出限制。答案漏列真实题名时，本地回答追加缺失出处。女娲回答遵循提示词，不假称本地追加策略能控制平台输出。
- 无模型时逐份展示相关资料摘录，不再只摘前三条；它仍不是模型综合判断。游客不展示片段数量、评分、候选数量、分页状态或检索报告。

## 生效位置

1. 网页经 `/chat/stream` 送往女娲：`prompts/nuwax_user_prompt.md` 每轮加载新规则，不显示在用户气泡。
2. 本地AnswerChain：`prompts/system_prompt.md`、`prompts/answer_prompt.md` 和文献检索逻辑，需重启本机API。
3. 女娲MCP：配置页停用再启用 `san-guo-travel-agent`，重新发现分页参数和工具说明，并新建对话。
4. 女娲平台系统提示词：将 `prompts/nuwax_agent_system_prompt.md` 替换至Agent系统提示词后发布。本地编辑不会自动发布远端Agent。独立NuwaClaw会话尤其需要此步骤。

仅改变回答策略与检索覆盖，没有新增PDF、重新嵌入、修改地图界面或公布密钥。文献范围是当前已入库且本次被判为相关的资料，不是所有32篇老师资料或所有学界研究。
