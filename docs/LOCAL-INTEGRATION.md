## 本地运行（不用 Docker）

本轮预览使用 mock 模型和独立临时业务库，不调用付费模型；原 `.env`、被跟踪的 `.venv` 未修改。

```powershell
cd D:\agent_threekingdom
$env:VECTOR_BACKEND = 'local'
$env:LLM_BACKEND = 'mock'  # 演示；真实模型需另按项目配置
& 'C:\Program Files\Python312\python.exe' -B -m uvicorn api:app --host 127.0.0.1 --port 8010 --app-dir src
```

打开 http://127.0.0.1:8010 ，从“目的地与行程”开始。不要双击HTML；端口已占用时不要重复启动。
