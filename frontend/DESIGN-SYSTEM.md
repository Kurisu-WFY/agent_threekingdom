# 寻迹三国 · 视觉规范 v1

实现入口为 styles.css。扩展既有令牌，不重命名既有语义；新页面直接复用以下规则，不新增字体 CDN、图片或依赖。

## 令牌速查

| 类别 | 令牌与取值 | 用法 |
|---|---|---|
| 间距 | --space-1…6 = 4 / 8 / 12 / 16 / 24 / 32px | margin、padding、gap；大区块可用 calc 组合 |
| 字号 | --text-xs/sm/base/lg/xl/2xl/3xl/display = 12/14/16/18/22/28/36/48px | 正文 base，辅助 sm；可信度提示至少 sm |
| 行高 | --leading-tight/title/body = 1.2/1.45/1.8 | 标题与正文分开，长文段间距 space-6 |
| 字体 | --font-body / --font-display / --font-numeric | 正文既有中文字体栈；书名宋体；数字英文无衬线 |
| 阅读宽度 | --measure-reading = 38em | 故事、史料与长回答限制行宽 |
| 层级 | --z-map/panel/chat/toast = 1/20/30/40 | 地图局部、面板、对话、通知依次叠放 |
| 阶段 | --phase-source/reading/explore/legacy | 寻源朱红、读史墨绿、探秘深铜、传承深墨绿；始终保留文字 |
| 动效 | --motion-fast/base/slow = 160/240/420ms | 使用既有 --layout-easing；--layout-duration 指向 slow |
| 点击与焦点 | --target-size = 44px；--focus-ring | 按钮/选择器/链接触屏尺寸；3px明确焦点描边 |

## 配色与文化元素

宣纸底（paper）与纸面（surface/surface-2）占主体；正文 ink，次级正文 ink-soft/muted。朱红 shu 只用于强调、当前章、印章、小型主按钮；墨绿 jade 辅助导航与选择状态；brass 只作分隔与装饰，正文不用浅铜金。深铜 brass-ink 仅用于有足够对比的专题/状态提示。

新增颜色只在 :root 声明。组件使用 var；透明层用 color-mix。史官SVG服色与肤色也复用令牌。地图保持既有字号、投影及地名/边界，故事墨迹减弱，不铺纹样；印章与编号用于信息结构，SVG保留替代文本。

地图坐标、描边、图标几何和断点不属于排版间距，保留精确数值。地图密集标记可通过同页章节列表和选择器操作。

## 组件状态

| 组件 | 默认 | 悬停 | 聚焦 | 禁用 | 选中 |
|---|---|---|---|---|---|
| 主按钮 | 小面积朱红、纸色字 | 深朱红 | 墨绿焦点描边 | 实色浅底、明确文字，无透明度淡化 | 语义支持时 aria-pressed、墨绿底线 |
| 次/文字按钮 | 纸面或透明、墨字 | 墨绿边框/浅底 | 同上 | 同上、不可操作 | 浅墨绿与底线，并保留文字 |
| 故事/章节/节点卡 | 纸面、细边框、章节编号 | 墨绿边框、轻阴影 | 同上 | 虚线/禁用语义 | 当前章节朱红边框与当前态文字 |
| 标签 | 明确分类文字 | 非交互不变 | 标签本身不聚焦，来源按钮可聚焦 | 不适用 | 不适用 |
| 印章 | 宋体编号/已寻迹文字 | 随所属卡片 | 随所属按钮 | 不使用色彩冒充进度 | 完成状态来自真实记录 |
| 表单 | 纸面、清晰边界 | 边界强调 | 同上 | 保留可读文字 | 原生 checked/selected，墨绿强调 |
| 滚动条 | 纸轨、墨色滑块 | 加深滑块 | 使用键盘滚动所属容器 | 不适用 | 不适用 |

史料记载/正史用墨绿；演义用铜色并保留“演义”文字；合理推断用虚线；争议用虚线边框及“存在不同说法”。待核验、待接入、未找到可靠记载统一采用 data-trust-state="unverified" 或 status-unverified：深朱红文字、暖纸底、明确边线，不可弱化成浅灰脚注。

## 响应式与可访问性

桌面主画布配右侧对话栏；1050px及以下对话展开为可收起浮层、故事卡单列；760px及以下进一步收拢双栏详情。长内容独立滚动，输入区保留。prefers-reduced-motion 将布局及装饰动效关闭，继续复用原动画取消逻辑。

关键文字/背景令牌组合经 design-system.test.cjs 验证达到 WCAG AA（最低4.91:1）；焦点与控件边界达到3:1。此检查不等于全站可访问性认证，后续内容和图片叠字仍需实际验收。

## 本轮验证

15组前端测试；375×667对话浮层、375px探索志、768px页面宽度、1440px首页视觉检查。使用8002临时静态服务，Docker后端未运行，因此本轮未重跑真实 /chat 联调。未改会话与视图切换核心机制；未启用预留旅游接口。
